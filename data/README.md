# Datasets — links only

**No dataset file, image, or model weight is ever committed to this repo.**
A 20 GB blob in git history cannot be removed without rewriting it for everyone.

Weights live in GitHub Releases or as a Kaggle Dataset. Fetch them with
`scripts/download_weights.sh`.

| Dataset | Purpose | Access | Licence |
|---|---|---|---|
| SCUT-HEAD Part A | head detection, real classroom CCTV | GitHub, direct | academic research use |
| SCB-Dataset5 | classroom behaviour, 20 classes | GitHub, direct | see repo |
| 300W-LP | head pose training | direct download | research |
| AFLW2000-3D | head pose eval | direct download | research |
| MRL Eye Dataset | eye-state / EAR calibration | direct download | see site |
| Roboflow (phone / cheating) | unauthorized objects | direct download | CC BY 4.0 |
| DIPSER | in-person engagement | SciDB / GitHub | CC-BY |
| MPIIFaceGaze | gaze validation | direct download | **CC BY-NC-SA — validation only** |

Requires an access request (not on the critical path): MEBOW, ETH-XGaze,
Gaze360, NTHU-DDD, YawDD, DAiSEE.
